# 🌈 키즈 플레이 v2.1

갤럭시탭에서 가로 화면으로 즐기는 **오프라인 어린이 게임 앱**입니다. Android WebView가 `app/src/main/assets/index.html`을 실행하며, 인터넷 연결 없이 플레이할 수 있습니다.

## 현재 포함된 게임

- **메모리 게임:** 4×4 / 4×5 / 6×6, 동물·과일·탈것 그림, 일시정지, 힌트 2회, 기기 내 최고 기록
- **숫자 놀이:** 그림 숫자 세기, 덧셈, 뺄셈. 숫자 범위 선택
- **한글 놀이:** 그림 보고 단어 찾기, 같은 글자 찾기, 빈칸 맞히기. 난이도 선택 및 한국어 음성
- **그림 퍼즐(개발 중):** 공룡·자동차·동물·바다·우주 각 6개, 총 30종. 쉬움 12 / 보통 24 / 어려움 36조각, 조각 끌어 놓기, 힌트, 섞기, 이어하기, 퍼즐 도감
- **장난감 선물/도감:** 게임 성공 시 상자 3개 중 하나 선택. 장난감 60종(공룡 30 + 탈것 30) 수집 목록 및 중복 없는 수집(60종 획득 전까지)

> **구현 상태 주의:** 퍼즐 그림은 현재 이모지 기반 SVG 일러스트이며, 실제 맞물리는 곡선형 조각과 3D 그림 30종은 아직 완성되지 않았습니다. 장난감 60종의 개별 3D 아트, 수집 완료 후 회차 초기화 기능은 미구현입니다. 실제 갤럭시탭에서의 APK 빌드/동작 검증이 필요합니다.

## Android 앱 정보

- 앱 이름: 키즈 플레이
- 버전: **2.1** (`versionCode 5`)
- 패키지: `com.kidsplay.app`
- 웹 게임: `app/src/main/assets/index.html`
- APK 빌드: `.github/workflows/build-apk.yml`

## APK 다운로드 및 설치

1. 저장소의 [Actions](https://github.com/c0129lee-dot/KIDS-GAME/actions) 탭을 엽니다.
2. **Build Kids Play APK** 워크플로의 가장 최근 **성공한 실행**을 선택합니다.
3. **Artifacts**에서 `KidsPlay-v2.1-debug` 파일을 다운로드합니다.
4. ZIP 압축을 풀고 `app-debug.apk`를 갤럭시탭에 설치합니다.
5. 필요하면 안드로이드의 **알 수 없는 앱 설치**를 허용합니다.

**업데이트:** 동일한 서명과 패키지로 빌드된 APK라면 기존 앱을 삭제하지 않고 설치할 수 있습니다. 단, GitHub Actions 디버그 서명이 빌드마다 달라질 수 있으므로 덮어쓰기가 실패하면 이전 앱을 삭제해야 할 수 있습니다. 앱 삭제 시 기기에 저장된 게임 기록과 수집 데이터가 지워질 수 있습니다.

## 향후 작업

1. 퍼즐 조각의 실제 맞물리는 곡선과 정확한 드래그 판정
2. 테마별 3D 장난감풍 그림 30종 및 연출/효과음
3. 장난감 60종의 개별 아트와 수집 완료/새 회차
4. 숫자·한글 게임의 5문제/정답 기준 통일, 난이도 선택 개선
5. 갤럭시탭에서 터치·저장·빌드 테스트

기록과 수집 상태는 기기 내부 저장소에 보관되며, APK 삭제나 앱 데이터 삭제 시 사라질 수 있습니다.
